# CoverMill · 封面工坊

> 一次输入，六种平台尺寸一起出图。

给中文自媒体人做的封面生成器：输入标题，选个模板，抖音、小红书、视频号、B 站、公众号、视频封面六种尺寸一次导出，打包成 ZIP。

**纯前端，零后端，图片全程只在你自己的浏览器里处理，不上传任何地方。**

---

## 为什么做这个

做封面的现状：

- **Canva / 稿定 / 创客贴**：好用，但导出带水印、模板要会员，而且一次只能做一张。
- **PS / Figma**：专业，但为了一个字改三遍，不值得。
- **各种「封面生成器」**：大多只出单一尺寸，换平台就得重做一遍。

真正烦人的不是「不会设计」，是**同一个封面要做六遍**：抖音 9:16、小红书 3:4、视频号 6:7、B 站 16:10、公众号 2.35:1、视频 16:9。每次都要重新排版。

CoverMill 就是把这一步省掉：**输一次，六张一起出**。

## 功能

| 能力 | 说明 |
|---|---|
| **20 套模板** | 渐变 / 几何 / 质感 / 排版 / 暗色，五组风格 |
| **六种尺寸** | 抖音、小红书、视频号、B 站、公众号、视频封面，可任意勾选 |
| **本地照片** | 支持全屏背景、上方配图、右侧配图三种用法，可调模糊与压暗 |
| **中文排版** | 中文按字断行、英文按词断行、字号自动缩放到刚好装下 |
| **批量导出** | 一次导出所有勾选尺寸，打包成 ZIP |
| **纯本地** | 不联网、不上传、不需要账号，断网也能用 |
| **响应式** | 手机竖屏、平板、桌面都能用 |

## 使用

**在线版**：打开 `index.html` 或访问部署地址，直接用。

**本地版**：下载 `index.html`，用浏览器打开。就这一个文件，没有任何依赖。

操作三步：

1. 写标题（可加副标题和署名）
2. 选模板，需要的话导入一张照片
3. 勾选尺寸，点「导出全部尺寸」

## 技术

- 纯原生 JavaScript，Canvas 2D 渲染，无框架、无构建步骤
- 单文件，约 30 KB
- ZIP 打包自己实现（store 模式 + CRC32），不依赖 JSZip 之类的库
- 字体走系统字体栈：`PingFang SC` / `Noto Sans SC` / `Microsoft YaHei`

## 已知限制

- 依赖系统字体，不同设备上字形会有细微差异
- 导出的是位图（PNG），不提供 SVG / PSD
- 没有云存储，刷新页面后输入内容会丢（模板选择保留）
